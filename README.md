# 📅 Board Room Booking System

A modern, real-time Board Room reservation system designed with the official **Microsoft Outlook Calendar & Microsoft Teams** interface. Built with an online shared live database so every team member sees reservations in real-time across all devices.

## ✨ Features
- **Official Outlook Calendar UI**: Styled with Microsoft Fluent Design, Segoe UI fonts, Outlook Blue palette, and weather indicators.
- **Strict Anti-Collision Engine**: Prevents double-booking automatically. If a time slot is already taken, overlapping reservations are blocked.
- **Real-Time Online Shared Database**: ERP-like live cloud synchronization. When any user books or cancels, all connected users see the update in real-time.
- **Instant Slot Freeing on Cancellation**: Easily cancel any meeting with a single click, instantly freeing the slot for everyone.
- **Full Viewport Responsive Grid**: Grid extends seamlessly to the bottom of the screen with live current-time indicator line.
